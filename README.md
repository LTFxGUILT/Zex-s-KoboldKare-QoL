## Features (V1.3/V1.4)

### Social & Chat
- Private messages (PM) with other Zex clients

- Soft teleport (smooth lerp)

### Host Tools

### Other

- Keybind rebinder
- Toast notifications (fully customizable)
- Session stats & welcome toast

## Controls

- **Insert** — Toggle menu
- **F9** — Clean screenshot
- **F10** — Cheat sheet (hold)
- **F1** — Toggle flying noclip
- **F2/F3** — Adjust fly speed
- **RightBracket / LeftBracket** — Spectate next/prev
- **R** — Reply to last PM
- **F6** — Quick save waypoint
- **F8** — Send party ping

**Full keybinds can be rebound in Settings.**

## Installation

1. Download the latest release (`.dll` file)
2. Put the `.dll` into your `BepInEx\plugins` folder
3. Start the game — the menu will appear automatically on **Insert**

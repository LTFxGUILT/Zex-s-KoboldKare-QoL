### Feature Voting

Community votes help decide what stays.

**Vote Week 1 (QoL) — ENDED**
- **Kept:** Clean leave, Quick Bar, UI Scale
- **Not kept:** Screenshot util as a vote feature, Spectate smoothing, Friends-only as a vote feature, HUD waypoints / copy-paste coords (vote panel)

If you try the plugin:
- Vote for features you want to keep
- Let me know what you think should be removed
- Suggest improvements
- Report anything that isn't working correctly

Not every experimental feature is guaranteed to make it into the final version.

## Bugs / Issues

If you find something broken, please report it.

When possible, include:
- What you were doing
- What you expected to happen
- What actually happened
- Any relevant error from the BepInEx console / log
- A screenshot if it helps explain the problem
